# Digital Media Analysis PWR: estymacja widoczności postów społecznościowych

Projekt na kurs AMC (Politechnika Wrocławska), zleceniodawca: Brand24.
Pytanie: czy da się oszacować widoczność (wyświetlenia) postu z liczby obserwujących i reakcji lepiej niż stałą × obserwujący i z jaką niepewnością.

## Zawartość
- `docs/M1_karta_eksploracji.pdf` — karta eksploracji danych (M1)
- `notebooks/01_eda.ipynb` (+ `.html`) — wstępna eksploracja danych
- `src/m1_figures.py` — wykres i liczby do karty M1
- `pitchdeck/claude/` — prezentacja (pptx, pdf, skrypt budujący)

## Dane
Surowy plik `reach_samples_students.csv` (12 500 wzmianek od Brand24) **nie jest** w repozytorium: zawiera dane osobowe autorów i dane zleceniodawcy.
Aby odtworzyć wyniki, umieść go w katalogu głównym repo i uruchom `python src/m1_figures.py`.
