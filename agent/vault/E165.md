# E165 · FB rule vs model by follower tier

## Question and hypothesis
- Question: the FB rule is ~x4 too high overall (E111). Does the model beat it in every tier, or only on average?
- Hypothesis: the model wins everywhere, the rule is uniformly bad.
- Refuted if: some tier is better served by the rule.

## Setup
- 402 FB posts; rule = `b24_estimated_reach`; model = ridge on likes + comments trained on X + YouTube; MAE per follower
  tier.
- Run: `python src/fb_rule_vs_model.py`; figure `figures/fb_rule_vs_model_*`.

## Result
| tier | n | rule MAE | model MAE |
|---|---|---|---|
| <1k | 15 | 1.012 | 0.451 |
| 1k-10k | 35 | 0.958 | 0.463 |
| 10k-100k | 90 | 0.996 | 0.364 |
| 100k-1M | 86 | 1.012 | 0.409 |
| >1M | 70 | 0.992 | 0.410 |

## Decision
The rule is uniformly ~1.0 (x10) in every tier; the model is 0.36-0.46. The model halves the error in every tier; there
is no tier where the rule should be kept. Add the figure to the product evidence.
