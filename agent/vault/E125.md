# E125 · CQR by reaction tier

## Question and hypothesis
- Question: a single interval width under-covered zero-reaction posts with raw quantiles (E34). Does CQR still need a
  width per reaction tier?
- Hypothesis: tier-specific widths improve coverage on the zero-reaction and high-reaction ends.
- Refuted if: global CQR already covers every tier.

## Setup
- CQR (LightGBM 5/95) with a global conformity quantile vs a per-tier quantile (fallback to global when a tier has < 30
  calibration posts).
- 5-fold brand CV; coverage by reaction tier (0, 1-10, 11-100, 101-1000, >1000).
- Run: `python src/cqr_tiers.py`.

## Result
| platform | coverage global | coverage per-tier | zero-reaction coverage | width |
|---|---|---|---|---|
| TikTok | 0.889 | 0.882 | 0.859 | 1.14 |
| YouTube | 0.902 | 0.892 | 0.892 | 1.71 |
| X | 0.891 | 0.890 | 0.902 | 2.07 |

- Per-tier calibration does not improve the aggregate and adds noise (0.882 / 0.892 / 0.890).

## Decision
Global CQR is enough; the zero-reaction gap of the raw quantiles is already fixed. Do not add per-tier widths.
