# E219 · Are X's zero-like posts what breaks X as a transfer source and target?

## Question and hypothesis
- Question: 52% of re-read X posts (and about 60% of export X posts) have zero likes. For those rows the likes +
  comments ridge has almost no input, so their level comes from the intercept. Is this what makes X the worst source
  and the hardest target in E201?
- Hypothesis (falsifiable): dropping zero-like rows from the source, or a two-part model (zero-like rows get the
  source's zero-like median y, other rows get a ridge fitted on the source's non-zero rows), improves X-as-source ->
  FB / IG and transfer to X by at least 0.03 MAE.
- Refuted if: neither the drop variant nor the two-part variant moves the primary comparisons by 0.03 or more.

## Setup
- Data: `train_combos.data()` (export TikTok 2,491 / YouTube 2,441 / X 1,803, FB 402, IG 642) and the same-moment
  re-read of X (`x_full_fetched.csv`, status ok, views present, dedup by mention_id keeping the last row; brand from
  the raw export). Ridge `fe.ridge` on C2 (log1p likes, log1p comments), rows pooled as in E201.
- Zero-like = likes == 0 (primary); sensitivity: likes == 0 and comments == 0.
- Variants: base (all rows); drop (zero-like source rows removed, all target rows scored with that ridge); two-part
  (target zero-like rows -> median y of source zero-like rows; other target rows -> ridge on source non-zero rows).
- **Primary comparisons (fixed before running):**
  1. Source: X-only (export) -> FB and IG, two-part vs base; the hypothesis needs the gain on both.
  2. Target: TikTok + YouTube + FB + IG -> export X, two-part vs base.
  The drop variant is the second test of the same hypothesis; both are reported.
- Also reported: X re-read as source and target; X + YouTube -> FB / IG; every E201 combination that excludes X ->
  X (export and re-read); every target split into zero-like vs non-zero rows.
- Scores: MAE, factor 10^MAE, brand-bootstrap CI (`va.mae_ci`), paired brand bootstrap of the MAE difference vs base
  (300 draws), median bias. No variant is chosen on FB / IG views.
- Run: `.venv/bin/python src/x_zero_split.py` (seconds, local).

## Result
MAE of log10 views (factor 10^MAE); paired diff = MAE(new) - MAE(base), brand bootstrap 300 draws, negative = better.
Zero = likes == 0. Zero-like share: export X 62%, re-read X 52%, FB 6%, IG 12%, TikTok + YouTube ~16%.

- Mean over the 15 training sets without X: export X target 0.627 / 0.573 / 0.684 (base / drop / two-part); re-read X
  target 0.491 / 0.491 / 0.532.
- The error on X targets sits in the zero-like rows: export X 0.701 zero-like vs 0.540 non-zero (base, TT+YT+FB+IG).
  The two-part median for zero-like rows (taken from sources where zero-like posts are rare and large) is worse than
  the ridge intercept.
- Sensitivity (zero = likes and comments both 0): X export -> FB -0.057 [-0.097, -0.011], -> IG -0.024; X + YouTube ->
  FB -0.005, -> IG +0.011; TT+YT+FB+IG -> X export drop -0.061, two-part +0.053; -> X re-read drop -0.015.
- Not a paired comparison (different targets), but notable: the same training sets score re-read X at 0.49 against
  0.64 on export X; most of "X is the hardest target" is the stale export label, not the zeros.

## Decision
Mostly refuted. As a source, X's zero-like rows explain little: X-only -> FB moves by 0.036 (CI includes 0) and
-> IG by 0.010; for the production source X + YouTube, dropping them makes FB / IG slightly worse. The two-part model
is worse on every X target. Dropping zero-like rows from the source does cut the error on export X by 0.079, but only
by 0.014 on the re-read X target, so it fixes stale export labels rather than the zero rows themselves. No change to
the transfer model; the re-read (E204) is the bigger lever for X as a target.
