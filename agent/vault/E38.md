# E38 · What is in the second Brand24 file?

## Question and hypothesis
The new file adds earlier checks of views and reactions for a meaningful share of posts.
Refuted if: the new columns are empty or contradict the main file.

## Setup
`reach_samples_students_with_history.csv` (2026-11-03, Brand24) against the main file on `mention_id`; coverage per platform; monotonicity of views across checks; time offset between `attributes_last_update` and `metrics_updated_at` where views are equal.

## Result
- Same 12,500 mentions; the old 19 columns are identical; 23 new columns.
- History (`history_1..3_*`): TikTok 341, X 349 posts; none on YouTube, Facebook, Instagram. Almost all created in 2026-08.
- Latest check (`current_*`): 1,230 posts (TikTok 350, X 364, YouTube 512, Instagram 4).
- Views never fall between checks (100% of posts).
- The same check is 2 h later in the new columns than in `metrics_updated_at` (summer), so the new times are read as Europe/Warsaw.

## Decision
Use the file for growth and forecasting on TikTok and X; YouTube only as two checks. Timezone assumption recorded in `agent/decisions.md`, question 3 to Brand24.
