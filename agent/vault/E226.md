# E226 · Information ladder: what each input buys

## Question and hypothesis
- Question: how much does each input reduce the error, from a constant median to the final model, in platform and out of platform? (Preprint figure replacing the "what the model needs" bars.)
- Hypothesis: likes give most of the gain everywhere; followers help little; comments and shares add ≤ 0.05 log10.

## Setup
- A, same platform: CatBoost `rt.FINAL`, 5-fold GroupKFold on E55 components (brand ∪ author ∪ text); steps: training-fold median, followers, + likes, + comments, + shares (= em.ENG).
- B, out of platform: ridge (fe.ridge) trained on export X + YouTube, scored on FB 402 / IG 642 (results_b.targets); steps: source median, comments only, likes only, likes + comments, likes + comments from the re-read source (E210). FB export reactions from E177.
- `src/info_ladder.py` (Kueue run; `--plot` renders locally).

FB likes + comments from the export (another time): x6.77. YouTube final x2.85 vs x2.90 in results_a (results_a fits on 75% of each training fold for CQR calibration).

## Decision
Supported: likes carry most of the signal on every platform; followers alone get to x3.8-6.0; comments and shares add little except on YouTube (3.17 -> 2.85). Out of platform the gap between median and likes is larger (x8.7-19.9 -> x2.5-2.7). Used as preprint Fig. "Co daje każda informacja".
