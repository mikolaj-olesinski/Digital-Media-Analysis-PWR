# E127 · Metapath2vec on the author-brand-hashtag graph

## Question and hypothesis
- Question: hand-built graph features gained at most 0.009 (E03/E06/E12/E29), GraphSAGE on the text graph was worse
  (E65) and spectral author-brand embeddings were worse (E122). Does the heterogeneous-graph method from the literature
  (metapath2vec) do better?
- Hypothesis: metapath walks (author-brand-author, brand-author-brand, author-hashtag-author) capture communities that
  hand features miss.
- Refuted if: no gain or worse.

## Setup
- Graph: authors, brands and hashtags as nodes; edges from posts (author-brand, author-hashtag, brand-hashtag).
- Metapaths A-B-A, B-A-B, A-H-A; 3 walks per start node, length 15, window 3.
- Skip-gram with negative sampling (5 negatives, dim 16), 3 epochs; author + brand + hashtag-mean embeddings (48 dims)
  added to the final CatBoost features.
- 5-fold brand CV; MAE per platform.
- Run: `python src/metapath2vec.py`. Literature: metapath2vec (KDD 2017), heterogeneous GNN (KDD 2024),
  SW-Metapath2vec (PLOS ONE 2024), see `docs/en/literature_notes.md`.

## Result
| platform | base | + metapath2vec |
|---|---|---|
| TikTok | 0.273 | 0.278 |
| YouTube | 0.456 | 0.480 |
| X | 0.467 | 0.480 |

## Decision
The heterogeneous-graph embedding hurts by 0.005-0.024, like every previous graph attempt. The graph topology is not
informative once followers and reactions are known: the only useful "graph-like" signal is the author's own past views
(E68, E119), which is a history signal, not a neighbourhood one. Close the graph line for this data; reopen only with a
real interaction/diffusion graph.
