# E213 · Results B re-scored with the re-read source (confirmatory)

## Question and hypothesis
- Question: E210 was positive (IG -0.053, FB flat). With the re-read source fixed, do the other Results B outputs
  (25-post shift, comments only, own-platform reference, FB 90% CQR band) hold or improve?
- Hypothesis (falsifiable): with the re-read source the zero-shot IG error is at or below x2.45 and FB stays at x2.4-2.5;
  the 25-post shift no longer helps IG by more than 0.01 (the level bias is gone); FB CQR 90% coverage stays >= 0.88
  overall, with >1M-follower pages still near 0.84.
- Refuted if: IG zero-shot factor > x2.45, or FB factor > x2.55, or FB 90% CQR coverage < 0.88.

## Setup
- **Spec (fixed before running, from E210-E212): ridge on log likes + log comments trained on the same-moment re-read
  X + YouTube, rows with missing likes / comments dropped (E210 primary). No deshrinking (E212 refuted). No age
  correction (E211).** Targets: `results_b.targets()` (FB 402 / 20 brands, IG 642 / 11 brands).
- Outputs as `results_b.py`, base (export X + YT) and new side by side: MAE, CI, factor, within x2, under share,
  median bias, 25-post median shift (200 draws), own-platform ridge (brand-grouped 5-fold CV), comments-only ridge;
  paired brand-bootstrap diff new vs base (2,000 draws).
- CQR 90% (E145 protocol): LightGBM quantile models (0.05 / 0.95) on the source, 20 random splits with 25% of the
  target brands for calibration, coverage and width on the rest; FB by follower tier (<10k / 10k-1M / >1M); IG overall
  (IG has 11 brands, so 2 calibration brands per split: indicative only).
- New file; `results_b` is not overwritten. Run: `.venv/bin/python src/results_b2.py` (seconds, local).

## Decision
Supported (no refutation condition met): with the re-read source, zero-shot IG is x2.41, equal to IG's own-platform
ridge (x2.41) and to the export model after a 25-post shift; the 25-post shift no longer helps (0.382 -> 0.386), so
the IG level bias is gone without any target posts. FB is unchanged (x2.44 vs own x2.42). The FB 90% band is a bit
narrower and covers 0.917; the >1M tier, the known weak spot (E145/E147), rises from 0.836 to 0.898 while <10k drops
to 0.845 (50 posts). Recommended Results B spec: ridge on likes + comments trained on the same-moment re-read X +
YouTube. `results_b.py` is left as it is; the parent decides whether the preprint switches.
