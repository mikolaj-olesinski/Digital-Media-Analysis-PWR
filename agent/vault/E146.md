# E146 · Widening the FB band for >1M

## Question and hypothesis
- Question: the >1M FB tier is under-covered (0.84-0.86, E132/E145). Does a fixed widening factor for that tier fix it?
- Hypothesis: a 1.3-1.5 factor brings coverage to about 90%.
- Refuted if: coverage barely moves.

## Setup
- FB transfer CQR; 20 random 75/25 brand splits; the >1M tier uses q_global x factor (1.0/1.3/1.5/2.0); coverage and
  width on the held-out >1M posts.
- Run: `python src/fb_widen.py`.

## Result
| factor | >1M coverage | >1M width | all coverage |
|---|---|---|---|
| 1.0 | 0.843 | 1.46 | 0.893 |
| 1.3 | 0.848 | 1.57 | 0.894 |
| 1.5 | 0.853 | 1.64 | 0.895 |
| 2.0 | **0.859** | 1.82 | 0.895 |

## Decision
Widening barely moves coverage (0.843 -> 0.859 at double width). The under-coverage of large pages is not a width
problem: the interval is mis-centred, not too narrow. Do not use a widening factor as a fix.
