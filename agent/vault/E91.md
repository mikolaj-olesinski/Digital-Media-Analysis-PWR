# E91 · Input subset chosen by source-to-source transfer

## Question and hypothesis
- Question: can the transferable inputs be chosen without the target, by training on one source platform and scoring on the other (stable or invariant subsets, Pfister et al. 2021, Rojas-Carulla et al. 2018)?
- Hypothesis: the search rediscovers likes + comments.
- Refuted if: it picks other subsets that transfer worse.

## Setup
- All 63 subsets of log likes, comments, shares, followers, comments per like, likes per follower; ridge. Source-to-source score: train on one source platform, MAE on the other, both directions. Target MAE of pooled ridge on both sources. Chosen subset = minimum source-to-source score.

## Result
- Chosen: X likes + comments (0.642, the reference); YouTube comments + comments per like + likes per follower (0.596 vs 0.604); TikTok comments + shares + followers + comments per like (0.497 vs 0.312).
- Oracle best on target: 0.305 / 0.577 / 0.583; all six inputs 0.476 / 0.580 / 0.612.
- Spearman between source-to-source and target MAE over subsets: 0.24 / 0.58 / 0.65.

## Decision
Refuted. With only two source platforms the source-to-source score is a weak guide (it fails badly on TikTok). Likes + comments stays the safe choice; followers help on YouTube and X but hurt on TikTok, so no subset is best everywhere.
