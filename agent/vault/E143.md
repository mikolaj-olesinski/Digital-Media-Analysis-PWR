# E143 · Facebook transfer with age

## Question and hypothesis
- Question: FB posts differ in age (2025 vs 2026) and views grow with age. Does adding log(age) to the X+YouTube ridge
  improve the FB MAE?
- Hypothesis: a small gain.
- Refuted if: the MAE rises.

## Setup
- Ridge on likes + comments (+ log age) trained on X + YouTube, applied to 402 FB posts; age = fetched - posted.
- Run: `python src/fb_age.py`.

## Result
| features | MAE | bias |
|---|---|---|
| likes + comments | **0.385** | +0.14 |
| + log(age) | 0.475 | +0.35 |

## Decision
Age hurts the FB transfer: the source age slope does not carry over (the FB sample has a different age mix). Do not add
it. Normalising the target to 30 days (E101) remains the right way to handle age on FB.
