# E163 · Which model to use when data is missing

## Question and hypothesis
- Question: E138/E161 corrupted the test set of a full model. If a feature is missing at scale, is it better to retrain
  without it (a specialised model)?
- Hypothesis: yes, the full model suffers from a feature it cannot use.
- Refuted if: the specialised model is not better.

## Setup
- Train three models per platform: full (ENG), followers-only, reactions-only; 5-fold brand CV.
- Test scenarios: all reactions set to missing, or all followers set to missing.
- Run: `python src/model_selection_missing.py`.

## Result
| platform | no reactions: full | no reactions: followers-only | no followers: full | no followers: reactions-only |
|---|---|---|---|---|
| TikTok | 1.139 | **0.583** | 0.294 | **0.276** |
| YouTube | 1.462 | **0.767** | 0.711 | **0.494** |
| X | 0.609 | **0.575** | 0.733 | **0.515** |

## Decision
When a feature is systematically missing, retrain without it: the specialised model beats the full model in every
scenario, dramatically so for TikTok without reactions (1.139 -> 0.583) and YouTube/X without followers (0.71/0.73 ->
0.49/0.52). Add this to the missing-data guidance; the degraded numbers in E138/E161 are the cost of using the wrong
model, not the floor.
