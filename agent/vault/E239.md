# E239 · Preliminary text analysis per platform

## Question and hypothesis
- Question: how do the texts differ across the five platforms (length, language, hashtags, links, mention type, sentiment, typical words)?
- Hypothesis: platforms differ strongly in style and in who writes (brands vs people); descriptive, no model.

## Setup
- All 12,500 mentions (2,500 per platform), title + content. Counts only: share with text, median chars / words, language, hashtags, @mentions, links, emoji, question marks, exact duplicate texts, AI labels for type and sentiment (mention_labels.csv), distinctive English words by log-odds, median views by type (TT / YT / X).
- No author names, handles, links or quotes are written. `src/text_eda.py` (seconds, local), `figures/text_eda_pl.png`.

## Results
- Median words TT 22 / YT 97 / X 29 / FB 77 / IG 76; English TT 94% / YT 97% / X 97% / FB 71% / IG 64%.
- Hashtags: IG 96% (median 10), TT 89%, YT 56%, FB 47%, X 20%. Links: YT 51%, X 40%, FB 34%. @mentions: X 53%.
- Type (AI labels): FB 85% promo, IG 59% promo, X 68% organic, TikTok 47% organic. Negative sentiment: X 22%, others 1-4%.
- Exact duplicate texts: FB 5.8%, IG 5.4%, others 1-2%. Facebook has almost no emoji (0.2% vs 10-24%): likely a data artefact.
- Distinctive words: TikTok fyp / viral / skincare, YouTube subscribe / playlist / timestamps, X wts + brand names, Facebook event and company names, Instagram digital marketing / e-commerce.
- Median views by type (TT / YT / X): organic 782 / 402 / 26, promo 721 / 607 / 48, spam 603 / 388 / 29 (descriptive).

## Decision
Descriptive. Facebook and Instagram are mostly brand content (promo), X is mostly people, which supports that FB / IG are a different post population from X / YouTube. Language labels are unreliable in places (an Indonesian word among "English" Instagram posts) and the type / sentiment labels are AI labels without a human check. Nothing changes in the model.
