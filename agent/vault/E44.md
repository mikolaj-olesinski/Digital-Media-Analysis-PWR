# E44 · Does the age of the view check explain part of the error of the final model?

## Question and hypothesis
- Question: views are checked anywhere from 7 h to months after posting (E38). Does knowing the age of the check improve the final now-cast model?
- Hypothesis: adding log10(hours from posting to the check) to the final model lowers MAE, most on X, where views still grow fast in the first day (E39).
- Refuted if: the paired gain has a CI including zero on all three platforms.

## Setup
- Data: all TikTok / YouTube / X posts with views > 0 (same rows as E32/E33).
- Base: final model (CatBoost MAE loss, 300 iterations, followers + reactions + missing flags, `reaction_tiers.FINAL`).
- New: base + log10 age of the check.
- Also: base model error by age-of-check bin.
- Validation: 5-fold brand-grouped CV, paired gain with brand bootstrap CI (`history.gain_ci`).

## Result
| | TikTok | YouTube | X |
|---|---|---|---|
| final model MAE | 0.273 | 0.456 | 0.466 |
| + age of check | 0.273 | 0.452 | 0.454 |
| gain (CI) | +0.000 (-0.002-0.003) | +0.003 (-0.001-0.008) | +0.012 (0.005-0.019) |
| checks < 1 day: posts | 53 | 384 | 531 |
| < 1 day MAE, base → + age | 0.385 → 0.341 | 0.414 → 0.391 | 0.458 → 0.410 |
| < 1 day bias, base → + age | +0.23 → +0.07 | +0.10 → -0.01 | -0.02 → -0.08 |

Note: E01 already had `metrics_age_days` in its cumulative "time" group, so this is the first separate test of it.

## Decision
Partly supported: a small gain on X only; on TikTok and YouTube the overall gain is zero, but the age column removes the over-estimate of checks younger than a day. Worth keeping in the final model as a cheap column; it does not change the headline numbers.

## Follow-ups
B05 (horizon), and add `log_age` to the final model in later experiments.
