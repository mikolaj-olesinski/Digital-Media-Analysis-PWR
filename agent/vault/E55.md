# E55 · Leakage audit: folds that also separate authors and copied texts

## Question and hypothesis
- Question: brand-grouped folds can still put the same author (1% / 9% / 3.5% of posts write about several brands) or the same copied text in train and test. How much does that flatter the headline numbers? And how much better is the model on brands it has already seen (random folds)?
- Hypothesis: grouping by brand ∪ author ∪ identical text raises MAE by ≤ 0.01 (most on YouTube); random folds lower it by 0.02-0.05.
- Refuted if: the stricter folds raise MAE by > 0.02 on any platform.

## Setup
- Components of the graph joining posts that share a brand, an author or the same normalised text (> 20 characters); 5-fold GroupKFold on them.
- Final model (CatBoost MAE, ENG) on: brand folds (usual), component folds, random 5-fold.
- Same posts, paired brand bootstrap CI.

## Result
Components joining brand, author and identical text: 174 / 156 / 159 groups (from 266 / 273 / 252 brands); the largest holds 28% / 40% / 34% of the posts.

| folds | TikTok | YouTube | X |
|---|---|---|---|
| brand (usual) | 0.273 | 0.456 | 0.466 |
| brand ∪ author ∪ text | 0.272 (+0.002, CI 0.000-0.003) | 0.457 (-0.001, -0.004-0.003) | 0.477 (**-0.011**, -0.020 to -0.003) |
| random (brands seen) | 0.270 (+0.003, 0.001-0.005) | 0.447 (+0.009, 0.004-0.012) | 0.469 (-0.002, -0.006-0.002) |

## Decision
Hypothesis mostly supported: the stricter folds change MAE by ≤ 0.002 on TikTok and YouTube and make X worse by 0.011, so the X headline is slightly optimistic (0.47 → 0.48); no platform moves by more than 0.02. The second half is refuted: seeing the brand in training helps little (≤ 0.009), so the model does not rely on brand identity. Brand-grouped CV stays the shared validation; report X as 0.47-0.48.
