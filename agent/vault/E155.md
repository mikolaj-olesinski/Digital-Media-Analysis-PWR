# E155 · Is the hybrid FB gain significant?

## Question and hypothesis
- Question: the hybrid improves FB MAE from 0.385 to 0.379 (E154). Is that difference real?
- Hypothesis: the gain is small but positive.
- Refuted if: the paired bootstrap CI includes zero.

## Setup
- Paired brand bootstrap (2000 draws) of the per-post absolute-error difference between the global and hybrid models on
  the 402 FB posts.
- Run: `python src/fb_hybrid_ci.py`.

## Result
- MAE global 0.385, hybrid 0.379, difference **-0.007**.
- 95% CI **[-0.035, +0.015]** — includes zero.

## Decision
The hybrid gain is not established: the CI includes zero and the point gain is 0.007. Keep the hybrid as an optional
spec for >1M (where the point gain is larger, 0.410 -> 0.372) but do not claim an overall improvement. The model card
keeps 0.385 as the FB number and mentions the hybrid as optional.
