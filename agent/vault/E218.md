# E218 · Does adding the previously view-less X posts change the X model?

## Question and hypothesis
- Question: the same-moment re-read gives views for 2,013 X posts, about 500 of which had no views in the Brand24
  export (E181: those are about x1.8 smaller). Does training on them lower the whole-stream X error, and is re-read X a
  better transfer source for FB / IG?
- Hypothesis (falsifiable): on the re-read target, the in-platform model trained with the previously view-less posts
  lowers whole-stream X MAE by at least 0.02, and re-read X transfers better to FB / IG than export X.
- Refuted if: the paired brand-bootstrap CI of the whole-stream MAE difference includes 0.

## Setup
- Data: `x_full_fetched.csv`, status ok, views present, dedup by mention_id (last row); y = log10(views clipped at 1).
  "New" posts = re-read posts not in the export view sample (`em.load`, view_count > 0); "old" = the rest.
- Features: re-read likes / comments / shares (log1p, NaN kept as missing), export log10 followers, log10 age in days
  at the re-read (fetched_at - created_at).
- Model: `rt.FINAL` (CatBoost, MAE loss, 300 iterations), 5-fold brand-grouped CV over all re-read X posts.
- **Primary (fixed before running):** whole-stream MAE on all re-read X posts, model trained with the new posts in the
  training folds vs without them (same folds, same test posts). Paired brand bootstrap of the difference (300 draws).
- Also: the same split scored on the new and the old posts separately; X re-read -> FB / IG ridge on C2 vs export X
  -> FB / IG; X re-read + export YouTube vs export X + YouTube. Export and re-read targets are never mixed.
- Run: `.venv/bin/python src/x_reread.py` (local if under a minute, else Kueue).

## Result
2,013 re-read X posts, 270 brands; 505 new (no export views), 1,508 old. Median log10 views new 1.67 vs old 1.86
(about x1.5 smaller, consistent with E181); zero-like share 55% vs 51%. MAE of log10 views, brand CV; paired diff =
with - without, brand bootstrap 300 draws.

| scored on | trained without new posts | trained with new posts | paired diff |
|---|---|---|---|
| **all re-read X (2,013)** | 0.444 (x2.78) [0.429, 0.461] | 0.440 (x2.75) [0.424, 0.458] | **-0.005 [-0.009, 0.000]** |
| new posts (505) | 0.474 (x2.98) [0.439, 0.514] | 0.460 (x2.88) [0.426, 0.498] | -0.014 [-0.028, -0.001] |
| old posts (1,508) | 0.435 (x2.72) | 0.433 (x2.71) | -0.002 [-0.005, +0.002] |

Transfer, ridge on C2 (paired diff = new source - base source):

| source | FB (402) | IG (642) |
|---|---|---|
| X export | 0.487 (x3.07) | 0.438 (x2.74) |
| X re-read, all | 0.520 (x3.31); vs export +0.034 [-0.007, +0.076] | 0.406 (x2.55); vs export -0.031 [-0.057, -0.010] |
| X re-read, old only | 0.509 | 0.400 |
| X export + YouTube export (base) | 0.385 (x2.43) | 0.435 (x2.72) |
| X re-read all + YouTube export | 0.397 (x2.49); +0.011 [-0.011, +0.033] | 0.404 (x2.54); -0.030 [-0.043, -0.019] |

- Adding the 505 posts to the X source: FB +0.011 [-0.002, +0.023], IG +0.006 [+0.002, +0.010] (slightly worse).
- On re-read X, the X-only source now over-predicts FB (median bias -0.39) where export X was closer (-0.23).

## Decision
Refuted. Training on the previously view-less posts lowers whole-stream re-read X MAE by only 0.005 (CI touches 0),
well under 0.02; the gain is confined to those posts themselves (-0.014). As a transfer source, re-read X helps IG
(-0.03, with or without YouTube) but not FB (+0.01 to +0.03, CI includes 0), and the 505 new posts add nothing to
transfer. The X model does not need them; the re-read changes the X label level, not what the model learns.
