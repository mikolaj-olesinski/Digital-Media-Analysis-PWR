# E126 · What range to report for a 0/0 post

## Question and hypothesis
- Question: for a post with 0 reactions at the first scan, what range of views should be reported? Same at the last
  check and at collection.
- Hypothesis: a wide, platform-specific range, with a long right tail.
- Refuted if: the range is narrow.

## Setup
- History file: posts with 0 likes and 0 comments at the first check (median age 11.7 h); 10-50-90% quantiles of views
  at the first and the last check.
- Main file: posts with 0 reactions at collection.
- Run: `python src/early_intervals.py`.

## Result
| when / platform | p10 | p50 | p90 | n |
|---|---|---|---|---|
| first check, X | 0 | **5** | 49 | 239 |
| first check, TikTok | 2 | **60** | 179 | 18 |
| last check, all | 1 | 18 | 263 | 257 |
| collection, TikTok | 1 | 69 | 246 | 99 |
| collection, YouTube | 2 | 79 | 3 383 | 697 |
| collection, X | 1 | 13 | 124 | 1 030 |

## Decision
Report a range, not a point: at the first scan a 0/0 post is likely under 50-180 views (platform-dependent), but the
p90 at collection is 124 (X) to 3 383 (YouTube). This is the "minimum detectable" statement for the client when a post
is scanned early. Update the model card.
