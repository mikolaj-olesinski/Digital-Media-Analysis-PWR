# E173 · Brand buzz in the Brand24 stream

## Question and hypothesis
- Question: does the number of mentions of the brand in the whole file in the 7 days before a post (all five platforms) explain views?
- Hypothesis: a brand that is talked about more right now gets more views per reaction.
- Refuted if: paired gains with CIs at or below zero in brand CV and on later months.

## Setup
- Columns: log10 mentions of the brand in [t-7d, t) across the 12,500-row file (no views needed, so it also exists on FB/IG) and the ratio to the brand's 90-day rate. Coverage 100%.
- Every time column uses only other posts whose view check was before the post (no own views, no future).
- Evaluation: final CatBoost (`em.ENG`) vs + columns, same brand folds, paired brand bootstrap; and a temporal split
  (train before 2026-06-01, test after, 1,253-1,588 test posts per platform). Run: `python src/time_momentum.py` via Kueue.

## Result
- Brand CV gain (TikTok / YouTube / X, 95% CI): -0.002 (-0.004 to +0.000) / -0.002 (-0.006 to +0.002) / -0.008 (-0.011 to -0.004).
- Temporal (train before 2026-06-01, test after): -0.006 (-0.011 to -0.002) / -0.026 (-0.034 to -0.015) / -0.009 (-0.017 to -0.002).
- Facebook transfer (402 posts): 0.385 -> 0.399, bias +0.14 -> +0.18.
- All four groups together: brand CV -0.001 (-0.004 to +0.003) / -0.019 (-0.027 to -0.011) / +0.001 (-0.006 to +0.008); temporal -0.011 (-0.018 to -0.005) / -0.099 (-0.114 to -0.078) / -0.011 (-0.022 to +0.001).
- YouTube's temporal test loses 0.03-0.10 with any added columns (age-at-check shift, E62), so temporal YouTube gains are not informative for small effects.

## Decision
Refuted. Buzz in the monitoring stream does not lift views; on FB it raises the bias.
