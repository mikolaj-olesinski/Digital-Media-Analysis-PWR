# E144 · FB tier-specific CQR widths

## Question and hypothesis
- Question: the global FB band under-covers pages above 1M followers (E132). Does a per-tier conformity quantile fix it?
- Hypothesis: coverage rises to about 90% in every tier.
- Refuted if: no change in the large tier.

## Setup
- CQR on the FB transfer; conformity score calibrated per follower tier (<10k, 10k-1M, >1M), fallback to global when a
  tier has fewer than 20 calibration posts; 5-fold brand CV.
- Run: `python src/fb_cqr_tier_fix.py`.

## Result
- Overall: global 0.925, tier 0.908.
- <10k: 0.920 / 0.920.
- 10k-1M: 0.949 / 0.909.
- **>1M: 0.857 / 0.857 (unchanged)** — the tier has fewer than 20 calibration posts in each fold, so it falls back to
  the global quantile.

## Decision
Per-tier calibration does not fix the large-page gap because the calibration sample per tier is too small. The practical
fix stays: widen the FB band for pages above 1M followers (or pool calibration across tiers/folds before fitting).
