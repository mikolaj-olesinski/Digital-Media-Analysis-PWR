# E116 · YouTube zeros as missing

## Question and hypothesis
- Question: 27% of YouTube posts have 0 likes and 0 comments and hold a third of the error (E27). Are those zeros real,
  or "not collected"? Does treating them as missing help?
- Hypothesis: if the zeros are collection artefacts, marking them missing (or dropping them) should improve the model.
- Refuted if: the change is negligible or negative.

## Setup
- Final model (CatBoost MAE, ENG) on 2 441 YouTube posts with views; 5-fold brand CV.
- Treatments: base (0 is 0); 0 -> NaN; 0 -> NaN + missing flag; 0 -> 0.5; drop zero-reaction posts from training.
- MAE overall, on the zero-reaction posts, and on the rest.
- Run: `python src/youtube_zeros.py`.

## Result
| treatment | MAE all | zero-reaction | non-zero |
|---|---|---|---|
| base | 0.456 | 0.661 | 0.379 |
| 0 -> NaN | 0.454 | 0.659 | 0.376 |
| 0 -> NaN + flag | **0.453** | 0.659 | 0.375 |
| 0 -> 0.5 | 0.454 | 0.659 | 0.377 |
| drop zeros from training | 0.499 | 0.845 | 0.370 |

- Zero-reaction share: 27.2% of YouTube posts.
- The best treatment gains **0.003** MAE; dropping the posts is much worse (the model needs them to learn the small end).

## Decision
Treating YouTube zeros as missing is not the big win the plan hoped for (H): +0.003, and the zero-reaction posts stay
hard (0.66). The zeros carry information (small posts), not just missingness. Keep the base treatment; do not drop.
The remaining error on these posts is the model's limit, not a coding choice. Update findings.
