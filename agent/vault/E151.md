# E151 · Can the >1M FB band be calibrated with a large-page model?

## Question and hypothesis
- Question: E147 showed the >1M band cannot be calibrated with the global model. Does a quantile model trained on source
  pages above 1M followers (with followers, E149) fix the coverage?
- Hypothesis: coverage reaches about 90%.
- Refuted if: coverage stays below 0.85.

## Setup
- Quantile LightGBM (5/95/50) on source pages >1M followers, features likes + comments + followers; CQR calibrated on
  25% of the FB >1M brands; 20 random splits.
- Run: `python src/fb_big_cqr.py`.

## Result
- 191 source posts above 1M followers; 70 FB target posts.
- Coverage **0.796**, width 1.72, MAE 0.474.

## Decision
Even a dedicated large-page model does not calibrate the >1M band (0.80 vs the global 0.84). With 70 posts and 191
source posts, the tier cannot support a 90% claim. Report the point (large-page model, MAE 0.368-0.47) but not a
calibrated band for >1M.
