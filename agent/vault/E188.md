# E188 · Earned media value: the error in money

## Question and hypothesis
- Question: What does the estimation error mean in money for a brand report?
- Hypothesis: The model keeps most brand EMVs within +-50% on X where the rule does not.

## Setup
- From E180: brand totals (>= 5 posts) x an assumed CPM of 5 USD per 1000 views (only a scale; ratios do not depend on it).
- Part of the critical review batch: `python src/critical_review.py` (via Kueue; E178 locally).

## Result
| | TikTok | YouTube | X |
|---|---|---|---|
| brands | 238 | 213 | 189 |
| model within +-50% | 61% | 57% | **47%** |
| rule within +-50% | 100% (= views) | 100% (= views) | **2%** |
| median abs error, model / rule (USD) | 76 / 0 | 57 / 0 | 1.4 / 41.6 |

## Decision
Supported. On X the rule's EMV is wrong for 98% of brands (median x11 high); the model gets half of them within +-50%. On TikTok / YouTube Brand24 already has the views; the model is only needed where views are missing.
