# E210 · Does same-moment re-read source data improve the transfer to Facebook and Instagram?

## Question and hypothesis
- Question: the X + YouTube ridge on log likes + log comments is trained on Brand24 export views, which are stale
  (E204: views x1.35 YouTube, x2.0 X since the export) and read at another moment than the reactions. Does training
  on the same-moment re-read (views and reactions from one request, 2026-11-08) transfer better to FB (402 videos)
  and IG (642 reels with visible likes)?
- Hypothesis (falsifiable): cleaner labels read at a similar age reduce under-prediction. IG improves by at least
  0.03 MAE (paired brand-bootstrap CI of the difference excludes 0); FB does not get worse by more than 0.02.
- Refuted if: the IG paired CI includes 0, or FB worsens by more than 0.02 (primary variant only).

## Setup
- Targets: `results_b.targets()` (FB 402 / 20 brands, IG 642 / 11 brands). Baseline FB 0.385 (x2.43), IG 0.435 (x2.72).
- Re-read loader: `data/processed/{youtube,x,tiktok}_full_fetched.csv`, `status == "ok"`, views present, deduplicated
  by mention_id (last row kept), y = log10(views clipped at 1), log1p likes / comments, brand from the raw export.
- **Primary variant (fixed before running): re-read X + YouTube, rows with missing likes or comments dropped (never
  filled with 0).** Same ridge as the base (`fe.ridge`, C2).
- Other variants, all reported: re-read X + YT fill-0; re-read X + YT + TikTok (drop-NaN); export X + YT and
  re-read X + YT stacked. No variant is chosen on FB / IG views.
- Grid: E201's 31 training-platform combinations with re-read TikTok / YouTube / X plus FB / IG (pooled rows), each
  left-out platform scored, next to the same grid on export TikTok / YouTube / X.
- Scores: MAE, factor, brand-bootstrap CI (300), paired brand bootstrap of the MAE difference vs base (2000 draws),
  median bias (+ = under), within x2, mean bias in the top quintile by true y and by predicted y, brand totals
  (brands with >= 5 posts: median log10 ratio predicted / true, share off by > x2, Kendall tau).
- Run: `.venv/bin/python src/reread_transfer.py` (seconds, local).

## Result
MAE of log10 views (factor = 10^MAE), brand-bootstrap 95% CI; paired diff = MAE(variant) - MAE(base), paired brand
bootstrap 2,000 draws (negative = better). FB 402 posts / 20 brands, IG 642 reels / 11 brands.
Source rows: re-read X 2,013 (505 of them have no export view), YouTube 1,376 after dropping missing likes/comments
(2,297 with fill-0), TikTok 426.

| variant | FB MAE (CI) | FB paired diff | IG MAE (CI) | IG paired diff |
|---|---|---|---|---|
| export X + YT (base) | 0.385 x2.43 (0.312-0.482) | - | 0.435 x2.72 (0.396-0.484) | - |
| **re-read X + YT, drop missing (primary)** | 0.387 x2.44 (0.325-0.457) | +0.002 (-0.038, +0.043) | **0.382 x2.41 (0.348-0.420)** | **-0.053 (-0.087, -0.027)** |
| re-read X + YT, fill 0 | 0.382 x2.41 | -0.004 (-0.041, +0.037) | 0.380 x2.40 | -0.055 (-0.087, -0.029) |
| re-read X + YT + TikTok | 0.381 x2.41 | -0.004 (-0.037, +0.031) | 0.385 x2.42 | -0.050 (-0.077, -0.028) |
| export + re-read stacked | 0.374 x2.37 | -0.011 (-0.029, +0.010) | 0.403 x2.53 | -0.032 (-0.046, -0.021) |

Under-prediction (mean bias, + = under), base -> primary:
- FB median bias +0.076 -> -0.051; top 20% by true y +0.435 -> +0.204; top 20% by predicted y +0.163 -> -0.054.
- IG median +0.281 -> +0.072; top 20% by true y +0.531 -> +0.286; top 20% by predicted y +0.320 -> +0.059.
- Within x2: FB 0.525 -> 0.483, IG 0.400 -> 0.481.
- Brand totals (median log10 predicted/true): FB -0.308 -> -0.065 (off >x2 53% -> 47%, Kendall 0.801 -> 0.778);
  IG -0.498 -> -0.245 (73% -> 55%, Kendall 0.782 -> 0.745).
- Likes coefficient (raw scale): 0.394 export -> 0.455 re-read; comments 0.037 -> -0.042.
- The primary IG transfer (0.382) equals IG's own-platform ridge (0.381).

Grid (31 training sets, median factor over the 15 sets that exclude the target), export -> re-read TikTok/YouTube/X:
TikTok x2.12 -> x2.29, YouTube x4.09 -> x2.16, X x4.37 -> x3.00, FB x2.58 -> x2.45, IG x2.65 -> x2.43.

## Decision
Supported: IG gains 0.053 (CI clear of 0, above the 0.03 threshold) and FB is flat (+0.002, within 0.02). All
variants agree in direction, so the choice is not fitted to FB / IG. The re-read is the better transfer source: it
halves the under-prediction of large posts and of brand totals, and as a target it makes YouTube and X look far less
"non-transferable" (YouTube x4.1 -> x2.2): much of E201's X/YouTube transfer gap was stale export labels. FB MAE does
not move; its gain is in bias and totals only. Caveat: the plan's pre-check had already seen this IG gain on 338 reels,
so the test is not blind; the primary variant was fixed in the card and every variant is reported.
