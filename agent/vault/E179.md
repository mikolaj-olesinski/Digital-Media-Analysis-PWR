# E179 · Does check age explain the noise ceiling? Fixed 30-day target

## Question and hypothesis
- Question: Is part of the E56 noise ceiling (posts with the same inputs differ x2.8 / x6.0 / x4.6) only a difference in check age, and does a fixed 30-day target lower the error?
- Hypothesis: Matching on age lowers the bound; a 30-day target is easier.

## Setup
- E56 nearest-neighbour pairs (Chebyshev 0.05, other brand) on the four log inputs, and the same with log10 check age added. Final model on views at check vs + log age vs a 30-day target (y + b (log 30 - log age), cross-sectional b from E101).
- Part of the critical review batch: `python src/critical_review.py` (via Kueue; E178 locally).

## Result
| | TikTok | YouTube | X |
|---|---|---|---|
| bound, inputs only (pairs) | 0.223 (183) | 0.388 (639) | 0.333 (999) |
| bound, inputs + age (pairs) | 0.243 (18) | 0.386 (249) | 0.331 (528) |
| MAE views at check | 0.273 | 0.456 | 0.466 |
| MAE + log age | 0.272 | 0.455 | 0.470 |
| MAE 30-day target | 0.272 | 0.449 | 0.466 |

- Check age p10 / median / p90: 7 / 35 / 91 days (TikTok), 0.1 / 25 / 95 (YouTube), 0.1 / 21 / 79 (X).

## Decision
Refuted. Age does not explain the ceiling: with age matched the bound is unchanged (YouTube 0.386, X 0.331). A 30-day target changes MAE by <= 0.007. The noise ceiling is real; the main conclusion stands.
