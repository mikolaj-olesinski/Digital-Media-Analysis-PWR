# E189 · External YouTube sample: does the model hold outside the Brand24 export?

## Question and hypothesis
- Question: can we fetch an independent sample of brand-related posts on YouTube, X and TikTok, and does the YouTube model
  hold on it?
- Hypothesis: the views-reactions relation survives outside the export, so the model transfers with a recalibration.
- Refuted if: the relation or the error is materially different on the external sample.

## Setup
- Feasibility tested with `yt-dlp 2026.10.26`: YouTube search works; TikTok reports "No working app info"; x.com answers
  HTTP 520; Instagram unchanged (B14). Plan and alternatives: `docs/en/external_sample.md`.
- YouTube: top-12 brands by mention count, `ytsearch` per brand, filters upload >= 2025-01-01, duration <= 15 min,
  views > 0, 5 per brand, **sorted by recency** (the first attempt sorted by views and produced a median of 53k - a
  selection bug, documented here).
- Fields: views, likes, comments, channel followers, date; channel id only, no channel names; the fetched CSV is
  git-ignored.
- Model: CatBoost on Brand24 YouTube rows (followers, likes, comments, missing flags, age), applied to the external rows.

## Result
| quantity | external sample | Brand24 YouTube |
|---|---|---|
| videos / rows | 53 (11 brands) | 2,441 |
| median views | **6,697** | **433** |
| p10 / p90 views | 529 / 948,498 | - |
| Spearman log views vs log likes | **0.933** | 0.71 |
| share with likes / comments / followers | 0.89 / 0.89 / 1.00 | - |
| model MAE | **0.726** | 0.456 (CV) |
| model bias | **+0.706** (under-estimates x5) | ~0 |
| after removing the level shift | **0.540** | - |
| calibration y on prediction | slope 0.83, intercept 1.27 | - |
| median baseline MAE | 1.599 | - |

## Decision
The external sample is feasible **only for YouTube** today; TikTok and X need an API, a login or a provider (plan in
`docs/en/external_sample.md`). On YouTube the relation survives (Spearman 0.93, slope 0.83) but the **level does not**: the
model trained on mentions under-estimates search-selected brand videos by about x5, and even after removing that shift the
MAE is 0.540 against 0.456 inside the export. Conclusion: the model is calibrated to the Brand24 mention population, not to
brand videos in general; external use needs a small recalibration set (E115). The result is a distribution-shift finding,
not a bug. Caveat: this sample is brand-centric (brand search plus the brand's channel), so part of the x5 shift is the
sample, not only the model; E191 samples third-party mentions and gets 0.44-0.69 MAE.
