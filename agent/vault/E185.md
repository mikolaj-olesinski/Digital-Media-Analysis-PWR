# E185 · Early virality alert from the first view check

## Question and hypothesis
- Question: With a first view check (history file), how precise is an alert for the posts that end in the top 5% / 1% of views?
- Hypothesis: First-check views make the alert much better than reactions alone.

## Setup
- E40 pairs (first and last check, brand CV). Alert = the k highest predicted final views, k = target size or 3x; precision and recall.
- Part of the critical review batch: `python src/critical_review.py` (via Kueue; E178 locally).

## Result
| top 5%, alerts = target size | TikTok | YouTube | X |
|---|---|---|---|
| reactions only | 0.71 | 0.64 | 0.35 |
| first check as-is | 0.82 | 0.79 | 0.71 |
| CatBoost first check + reactions + ages | **0.82** | **0.86** | **0.71** |

- With 3x alerts, recall 0.82 / 1.00 / 0.94. Top 1% has 3-4 posts per platform: not measurable.
- 289-336 posts per platform.

## Decision
Supported. A single early view read doubles the alert precision on X (0.35 -> 0.71) and lifts YouTube to 0.86. This is the alerting product; the static model is not (E106).
