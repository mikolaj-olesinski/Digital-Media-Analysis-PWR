# E154 · Hybrid FB model

## Question and hypothesis
- Question: combine the global transfer (pages <1M) with the large-page model (>1M, E150). Does the hybrid beat the
  global model on all 402 posts?
- Hypothesis: a small overall gain from fixing the tail.
- Refuted if: no gain.

## Setup
- Global: ridge on likes + comments, all sources. Large: ridge on likes + comments + followers, source pages >1M.
- Hybrid: large model for FB pages >= 1M, global otherwise.
- Run: `python src/fb_hybrid.py`.

## Result
| model | MAE all | MAE >1M | MAE <1M |
|---|---|---|---|
| global | 0.385 | 0.410 | 0.380 |
| **hybrid** | **0.379** | **0.372** | 0.380 |

## Decision
The hybrid is the right FB spec: small overall gain (0.006) and a clear gain on the >1M subset (0.410 -> 0.372). The
band still cannot be calibrated for >1M (E151); report the point with a caveat and the calibrated band for <1M.
