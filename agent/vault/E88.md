# E88 · Adapting the out-of-platform model to the target's reaction structure

## Question and hypothesis
- Question: E87 showed that mapping reaction scales hurts. Can the model instead be adapted to the target platform's reaction structure (likes, comments, shares, followers and their ratios), still without target views: by weighting source posts that look like the target, by mixing per-source models, or by predicting views per like?
- Hypothesis: importance weighting or a source mixture lowers the out-of-platform MAE.
- Refuted if: ridge on raw likes + comments stays best everywhere.

## Setup
- Leave one platform out on TikTok / YouTube / X, target-fold brands removed (as E13). Domain classifiers (CatBoost) on inputs plus comments per like, shares per like, likes per follower; never on views.
- Importance weights: source posts weighted by p(target | x) / p(source | x), clipped to 0.05-20. Source mixture: one model per source platform, mixed per target post by p(source k | x). Views per like / per reaction: model predicts log views − log likes (or reactions), added back. Raw + structure: raw inputs plus ratios and within-platform percentiles. Ridge on likes + comments and CatBoost; then a shift fitted on n target posts (E15).
- Same adaptations fixed for the FB / IG hand-check sample before any view is seen (`fbig_preregistered_v2.csv`, weights fitted on all FB / IG posts in the file), scored together with E82.

## Result
- Weights concentrate on few source posts: effective sample share 6-8%.
- X: importance weights help: ridge +0.023 (0.020-0.026), CatBoost +0.032 (0.016-0.047; 0.641 -> 0.609); views per like +0.013; ridge source mixture +0.015.
- TikTok: every adaptation is worse than raw ridge (0.312): importance weights -0.07 / -0.14, mixture -0.13 / -0.16, views per like -0.002.
- YouTube: all within ±0.04 of raw ridge (0.604), none clearly better.
- Ranking (Spearman) almost unchanged. With 25-50 calibration posts: X best is CatBoost raw + structure (0.520-0.528, as E87), TikTok and YouTube raw ridge.
- FB / IG pre-registered: importance-weighted ridge median 2.52 FB / 1.52 IG (log10), views per like 2.27 / 1.80; effective sample share 8% FB, 4% IG.

## Decision
Partly refuted. Adapting to the target's reaction structure helps only on X (+0.02 to +0.03), the platform least like the others, and hurts on TikTok. Ridge on raw likes + comments stays the robust default for an unseen platform; importance-weighted ridge is a candidate to check on FB / IG with the hand check.
