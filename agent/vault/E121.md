# E121 · New recency, sequence and text columns

## Question and hypothesis
- Question: do columns not in the final model help — post sequence within a brand, days since the previous post,
  brand/author activity in the last 30 days, hour/weekday, and text-surface features (URL, hashtag, mention, emoji,
  question/exclamation, capitals, digits)?
- Hypothesis: recency and activity carry a little extra signal.
- Refuted if: no gain.

## Setup
- Final CatBoost features + 14 new columns; 5-fold brand CV; MAE per platform.
- Run: `python src/new_columns.py`.

## Result
| platform | base | + new columns |
|---|---|---|
| TikTok | 0.273 | 0.271 |
| YouTube | 0.456 | 0.460 |
| X | 0.467 | 0.466 |

- TikTok -0.002, YouTube +0.004 (worse), X -0.001.

## Decision
No usable gain; the columns add noise more often than signal. Do not add them. The final feature set stays followers,
reactions and missing flags. Consistent with E05 (text stats about 0.01), E49 (context <= 0.003) and E84 (time/country
<= 0.005).
