# E194 · YouTube re-fetch: how stale are the export views?

## Question and hypothesis
- Question: the export's YouTube views were read at an unknown date; how far are they from the public counts today?
- Hypothesis: YouTube views grow more slowly than TikTok's and remain close.
- Refuted if: the counts differ by more than the age effect or do not rank-correlate.

## Setup
- 60 random YouTube mentions with views > 0.
- Re-read with `yt-dlp --dump-json` (views, likes, comments) on 2026-11-08; compare with the export.
- Run: `python src/youtube_refetch.py`.

## Result
| quantity | value |
|---|---|
| readable / attempted | **58 / 60** |
| median new/old views | **1.516** |
| p10 / p90 ratio | 1.006 / **25.279** |
| within 5% / within 20% | **0.19 / 0.29** |
| Spearman log views old vs new | **0.857** |
| median views old -> new | 283 -> 552 |

## Decision
YouTube export views are **much staler than expected**: the median post has 1.5x more views now and the top decile 25x;
only 19% are within 5%. Ranking holds (0.857), so the model's ordering is safe, but any level comparison must normalise by
age or use a common check date (E101). This also explains part of the external "top stratum" gap: the export understates
current popular videos. The practical rule: report the check date and the age, never compare raw levels across checks.
