# E177 · Facebook on Brand24's own likes and comments

## Question and hypothesis
- Question: the FB transfer (E93/E95) used reactions and comments fetched together with the views. In production Brand24
  only has its own counts. How good is the same model on them?
- Hypothesis: worse, because Brand24's FB likes are lower and it collects almost no FB comments.
- Refuted if: MAE stays within 0.05 of the fresh-count MAE.

## Setup
- 402 FB videos / Reels with fetched views (E95). Ridge on log1p(likes) + log1p(comments) trained on X + YouTube.
- Inputs: fresh counts vs the Brand24 file's `likes` / `comments` for the same mentions; plus a shift fitted on 25 FB posts
  (200 draws) and Brand24's reach column.

## Result
| inputs | MAE (CI) | factor | bias | Spearman |
|---|---|---|---|---|
| fresh likes + comments | 0.385 (0.312-0.482) | x2.4 | +0.14 | 0.91 |
| **Brand24 likes + comments** | **0.831** (0.660-0.976) | x6.8 | +0.70 | 0.65 |
| Brand24 counts + shift on 25 posts | 0.681 | x4.8 | | |
| Brand24 reach | 1.119 (0.845-1.419) | x13 | -0.20 | 0.55 |

- Fresh reactions are a median x2.0 above Brand24's likes; Brand24's FB comments are almost all zero.
- The comparison is not clean: Brand24 read the counts early, the views were read months later; the model on Brand24
  counts sees an older post than the view it is scored on.

## Decision
The FB transfer numbers (0.345 / 0.385) hold only with fresh, complete reactions and comments. On Brand24's current FB
fields the model is x6.8, still better than the reach rule (x13) but far from the headline. Requirement for production:
collect all reactions and comments for FB at the time of the estimate.
