# E200 · Full Facebook sweep: why only 470 of 2,500 posts were attempted

## Question and hypothesis
- Question: the Facebook slice has 2,500 posts but the measurement sample was 470 attempts. Is the rest unmeasurable, or did
  we stop early?
- Hypothesis: only video/Reel URLs expose a public view count; ordinary posts have none.
- Refuted if: the remaining posts have video IDs and readable counters.

## Setup
- Walked every Facebook row with a URL (2,500) with the same public watch-page fetcher, resumable, 0.4 s delay, 2 workers.
- Run: `python src/fb_full.py`.

## Result
| status | rows |
|---|---|
| **ok (views read)** | **402** |
| gone (video removed) | 68 |
| error (no video id - ordinary post/photo) | **2,030** |
| **total** | **2,500** |
| sum of views (402 posts) | **29,346,471** |
| median views | 1,413.5 |

## Decision
The 470 attempts were **all the Facebook video posts in the slice**; the other 2,030 are ordinary posts/photos, which have
no public view count at all (the same limit as Instagram). So the Facebook ground truth is 402 posts, not 2,500 - not a
stopping point, but the measurable subset. Any future Facebook work should treat the 402 as the complete measurable
population of this export, and ordinary posts as unmeasurable without the owner's insights.
