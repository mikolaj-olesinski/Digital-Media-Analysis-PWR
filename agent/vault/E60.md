# E60 · Early-reaction forecast without views (the Facebook / Instagram situation)

## Question and hypothesis
- Question: on FB/IG there are no views at all, only reactions. Can later likes be forecast from early likes (TikTok, X history), and does chaining forecast reactions → now-cast model give a better view forecast than E41 (reactions and ages straight to views, 0.37 / 0.54 on TikTok / X)?
- Hypothesis: likes forecast beats persistence by ≥ 0.05; the chain is within 0.03 of E41 (not better: it adds the now-cast error).

## Setup
- First-last pairs on TikTok and X. Likes and comments at the last check forecast by CatBoost on reactions, followers and ages at the first check (growth target). Chain: forecast reactions into the final now-cast model trained on the main file without the test brands. Upper bound: the chain with the true later reactions.
- 5-fold brand CV, paired brand bootstrap CI.

## Result
First-last pairs with reactions at both checks: TikTok 331, X 282.

| | TikTok | X |
|---|---|---|
| later likes, persistence | 0.230 | 0.147 |
| later likes, CatBoost | 0.162 (+0.068, CI 0.044-0.097) | 0.149 (-0.001) |
| views: E41 CatBoost on reactions + ages | 0.365 | 0.525 |
| views: chain forecast reactions → now-cast | 0.332 (**+0.034**, 0.012-0.058) | 0.492 (+0.033, -0.010-0.077) |
| views: chain with true later reactions (upper bound) | 0.289 (+0.076) | 0.415 (+0.110) |

## Decision
Hypothesis refuted in the useful direction: chaining forecast reactions into the now-cast model beats the direct E41 forecast on TikTok (+0.034, CI above zero) and probably on X (+0.033, CI includes zero). Likes on TikTok keep growing and are forecastable (+0.068 over persistence); on X they barely change between checks (as in E45), so the gain on X comes from the now-cast model, not the likes forecast. For FB/IG, where only reactions exist, the chain is the recommended way to forecast views from an early check (still a transfer assumption).
