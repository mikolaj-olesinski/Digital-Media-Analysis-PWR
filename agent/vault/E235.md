# E235 · Sudden spikes of small accounts: views far above what an account of that size normally gets, from reactions and followers only

## Question and hypothesis
- Question (slides): can we find a post whose views are far above the account's usual (e.g. an account with ~100 followers and ~500 views that suddenly has 50k), without using views as input?
- Hypothesis: yes, likes relative to followers expose it; an own-history baseline cannot be tested (few earlier posts).

## Setup
- Baseline = out-of-fold linear fit of log10 views on log10 followers per platform (the usual for that account size). Spike = true views >= 30x (or 100x) the baseline. Scores without views: lift (ridge estimate from likes + comments minus the baseline), like rate (log likes - log followers), the estimate alone. E55 component folds. AUC, precision in the top 1% / 5%.
- B: own baseline = posts whose author has >= 2 earlier posts in our data (TT 19, YT 145, X 62), spike >= 10x their median.
- `src/spike_detect.py` (seconds, local).

## Results
- Spike >= 30x (5.5% / 5.5% / 3.4% of posts), lift: AUC 0.98 / 0.86 / 0.89 (TT / YT / X), precision top 1% 1.00 / 0.75 / 0.71, top 5% 0.78 / 0.51 / 0.36. Like rate alone is as good (0.98 / 0.86 / 0.84); the estimate that ignores followers is worse (0.96 / 0.78 / 0.86).
- >= 100x: AUC 0.99 / 0.82 / 0.93 (few posts: TT 59, YT 44, X 14).
- The case in the question exists on TikTok: 23 accounts with <= 1000 followers and a post >= 100x their usual (median 214 followers, usual ~580 views, 9,295 likes, 184,522 views); 96% of them are in the top 5% of the lift. YouTube 4 such posts, X none.
- B: too few spikes to test (1 / 5 / 2 of 19 / 145 / 62); YouTube AUC 0.50 on 5.

## Decision
Supported on TikTok, weaker on YouTube and X. A big spike against the account size is visible from likes per follower, no model needed. The baseline is the typical account of that size, not the account's own history (not testable here; E70-E72 say authors keep a level beyond followers). Nothing is time-resolved: it is a spike against what the account size normally gets, not a measured sudden change. Presentation only.
