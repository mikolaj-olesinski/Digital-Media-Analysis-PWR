# E192 · TikTok re-fetch: do the export views match the public counts today?

## Question and hypothesis
- Question: the export's TikTok views were read at an unknown date; how far are they from the public counts now?
- Hypothesis: views are stale but rank-stable; most posts changed by less than 10%.
- Refuted if: the counts differ by more than the age effect or do not rank-correlate.

## Setup
- 60 random TikTok mentions with views > 0 from the export.
- A headless Chromium (Playwright, mobile UA) opens each public post and reads `playCount`, `diggCount`,
  `commentCount`, `shareCount` from the page HTML.
- Compare with the export values; run: `node .tools/browser/tt_refetch.mjs` (local helper, script not committed).

## Result
| quantity | value |
|---|---|
| readable / attempted | **40 / 60** (20 hit a login wall or captcha; a second retry with longer waits changed nothing) |
| median new/old views | **1.068** |
| p10 / p90 ratio | 1.006 / **3.066** |
| within 5% / within 20% | 0.45 / 0.65 |
| Spearman log views old vs new | **0.918** |
| median views old -> new | 759 -> 849 |

## Decision
The export's TikTok counts are close but stale: the median post grew 7%, the top decile grew 3x, and only 45% are within
5%. Ranking is preserved (0.918), so the model's ordering is safe, but any level comparison must use a common check date
or an age correction (E101). A third of the posts could not be read anonymously, which is the practical ceiling for
TikTok without the Research API.
