# E50 · Text: local sentence embeddings and TF-IDF in the final model and without reactions

## Question and hypothesis
- Question: E05 found TF-IDF worth +0.011-0.016 on YouTube and X with extra trees. Do multilingual sentence embeddings (local, `intfloat/multilingual-e5-small`) add more on top of the final CatBoost model, and how much does text give when there are no reactions (the FB/IG and posting-time situation)?
- Hypothesis: embeddings add ≤ 0.01 with reactions, but ≥ 0.03 on top of followers alone on YouTube and X.
- Refuted if: both CIs include zero.

## Setup
- Embeddings of title + content (links removed, 256 tokens), normalised; PCA 16 fitted on all mentions without labels. TF-IDF (1-2 grams, min_df 3) + SVD 16, also unsupervised. Computed on homelab3; text never leaves the machine.
- With reactions: final model + 16 embedding / TF-IDF components. Without reactions: followers + flags (base) vs + embeddings / TF-IDF / all E49 context.
- 5-fold brand-grouped CV, paired brand bootstrap CI.

## Result
| | TikTok | YouTube | X |
|---|---|---|---|
| final model + embeddings (e5, PCA 16) | +0.003 (-0.001-0.007) | -0.009 (-0.017 to -0.001) | **+0.011 (0.002-0.020)** |
| final model + TF-IDF SVD 16 | -0.003 (-0.006-0.000) | -0.006 (-0.014-0.001) | +0.002 (-0.005-0.009) |
| no reactions: followers (MAE) | 0.583 | 0.767 | 0.575 |
| no reactions: + embeddings | +0.009 (0.003-0.016) | **+0.051 (0.036-0.064)** | +0.018 (0.008-0.028) |
| no reactions: + TF-IDF | +0.005 (-0.001-0.012) | +0.051 (0.036-0.065) | +0.010 (-0.003-0.021) |

Embeddings computed on homelab3 with `intfloat/multilingual-e5-small` (weights downloaded once, no API). Cached as `data/processed/embeddings_e5_cache.pkl` (git-ignored).

## Decision
Partly supported. Next to reactions, embeddings help only on X (+0.011) and hurt on YouTube (-0.009); TF-IDF adds nothing with CatBoost (E05's +0.011-0.016 was with extra trees and more text features). Without reactions, text is worth +0.051 on YouTube (both methods equal) but only +0.018 on X and +0.009 on TikTok, so the "≥ 0.03 on YouTube and X" half holds only for YouTube. Text matters where reactions are missing (FB/IG transfer, posting time), not for the now-cast.

## Follow-ups
Use embeddings in the posting-time model (E43 used TF-IDF SVD); a fine-tuned text model is not worth it at this gain.
