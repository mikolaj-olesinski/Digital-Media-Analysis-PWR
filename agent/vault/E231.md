# E231 · Confidence model: can we tell in advance which posts the estimate will hit?

## Question and hypothesis
- Question (slides): instead of "is it a large post", can a second model say how sure we are, so that e.g. 80% of posts get a smaller error, and how large is the error on the rest?
- Hypothesis: weak; most of the remaining error is the author level (E70-E72), which the fields do not carry.

## Setup
- Base: final CatBoost out-of-fold predictions (`results_preds.csv`, E55 component folds), TT 2491 / YT 2441 / X 1803.
- Confidence models, out-of-fold with the same component folds, features em.ENG + the estimate: CatBoost regression of |error|; CatBoost classifier P(|error| < x2). Simple rule: total reactions. Oracle: true |error|.
- Risk-coverage: error x10^MAE on the most trusted 50-90% and on the rest; classifier thresholds 0.5-0.8. `src/confidence.py` (seconds, local).

## Results
- AUC for "error > x2": error model 0.54 / 0.62 / 0.53; classifier 0.55 / 0.63 / 0.54; reactions rule 0.49 / 0.65 / 0.53. Spearman predicted vs true |error| 0.08 / 0.29 / 0.08.
- Most trusted 80% (error model): x1.83 / x2.62 / x2.92, rest x2.05 / x4.32 / x3.55 (all x1.87 / x2.90 / x3.03). 50%: x1.78 / x2.28 / x2.82.
- Reactions rule, top 50%: x1.87 / x2.26 / x2.83. Oracle 80%: x1.47 / x1.98 / x2.10.
- Classifier P >= 0.8: 8.4% / 1.8% / 0.4% of posts, actually within x2 70% / 56% / 63% (overconfident); P >= 0.6: 77% / 19% / 5% of posts, x1.80 / x2.03 / x2.50.

## Decision
Supported (weak). The fields and the estimate barely tell which posts will be hit: only YouTube gains (top 50% x2.28 vs x2.90), and there the reaction count does the same. TikTok and X stay within ~x0.1. The classifier's probabilities are not calibrated. Presentation only (backup slide), no change to the model.

## Follow-ups
None; author history (E70-E75) is the only known signal of the remaining error.
