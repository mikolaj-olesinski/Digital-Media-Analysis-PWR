# E159 · FB brand-total interval scaled by the number of posts

## Question and hypothesis
- Question: a constant 80% width covers only 0.737 of 19 FB brands (E158). Does scaling the width by
  sqrt(n_median / n_posts) improve the coverage?
- Hypothesis: yes, small-sample brands need a wider interval.
- Refuted if: coverage does not move.

## Setup
- 19 FB brands >= 5 posts; leave-one-brand-out calibration and width; scaled width = q80(|residual|) *
  sqrt(18 / n_posts).
- Run: `python src/fb_brand_interval.py`.

## Result
- Constant width: coverage **0.737**.
- N-scaled width: coverage **0.789** (median n = 18 posts).

## Decision
Scaling by the number of posts improves the 80% coverage from 0.737 to 0.789, but it is still below 0.80 with 19
brands. Use the scaled width as a heuristic for FB brand totals and keep the warning; do not claim calibrated brand
intervals on FB.
