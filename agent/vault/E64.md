# E64 · A separate model for posts without likes and comments

## Question and hypothesis
- Question: 23% of YouTube and 55% of X posts with views have no likes and no comments; the final model has little to go on there. Does a model trained only on such posts, with posting-time columns, embeddings and context (E52 groups), do better on them?
- Hypothesis: on zero-reaction posts the separate model beats the final model by ≥ 0.03 on YouTube and ≥ 0.01 on X; the all-post model with the same columns is about as good.

## Setup
- Evaluated only on zero-reaction posts (TikTok skipped: 90 posts). Final model (all posts, ENG); all-post CatBoost with ENG + posting-time + embeddings + context; zero-reaction-only CatBoost with followers + posting-time + embeddings + context. 5-fold brand CV, paired brand bootstrap CI.

## Result
Evaluated on posts with 0 likes and 0 comments (YouTube 665, X 991; TikTok 90 skipped):

| | YouTube | X |
|---|---|---|
| final model (all posts) | 0.662 | 0.493 |
| all posts, + text and context | 0.667 (-0.005, CI -0.029-0.020) | 0.462 (**+0.030**, 0.016-0.045) |
| zero-reaction posts only, text and context | 0.672 (-0.010) | 0.482 (+0.011, -0.003-0.025) |

## Decision
Partly refuted: a separate model for zero-reaction posts does not help (too few posts to learn from). Adding text and context to the all-post model helps the zero-reaction posts on X (+0.030) but not on YouTube, where these posts remain the hardest (0.66). YouTube zeros may be missing data (E27, Q1), which no feature can repair.
