# E225 · Stack Exchange as a sixth platform with public views (evaluation only)

## Question and hypothesis
- Question: does the ridge on log1p(likes) + log1p(comments) trained on X + YouTube (export, as in results B) estimate
  the view count of Stack Exchange questions?
- Hypothesis (falsifiable): transfer error is within x1.5 of the own-platform ridge (brand-grouped 5-fold CV on Stack
  Exchange), i.e. factor(transfer) / factor(own) <= 1.5.
- **Refuted if: factor(transfer) / factor(own) > 1.5.**

## Setup
- Data: public official API (api.stackexchange.com 2.3, no key, CC BY-SA), questions created 2026-04-01 .. 2026-08-31,
  English sites only, one `search/advanced` request per (brand, site) pair, <= 100 questions per pair. Brands: the
  348 export brands minus names that are common words (`ambiguous_name` in `brand_industry.csv`); sites matched to the
  brand industry (stackoverflow, superuser, android, apple, gaming, travel, mechanics, money, diy, webapps). The brand
  must appear whole-word in title or body. Quota ~300 requests / day / IP; `quota_remaining` and `backoff` respected,
  reserve of 12 left, no key, no proxy. Owner fields other than reputation are dropped before storing.
- Primary mapping (fixed before scoring): likes = up_vote_count (fallback max(score, 0) if missing);
  comments = answer_count + comment_count. Variants: likes = max(score, 0); comments = answers only.
- Source model: `fe.ridge()` (StandardScaler + Ridge) on log_likes, log_comments, X + YouTube export rows (`em.load`).
- Scores: MAE log10 views with brand-bootstrap CI (`fe.score`), factor 10^MAE, median bias, share within x2, share
  under-predicted, Spearman. Reference: same ridge on Stack Exchange, brand-grouped 5-fold CV. Grid row: E201 style
  (`train_combos.data()`), Stack Exchange as target for each single platform and the pooled others.
- Caveat stated in advance: views accumulate over months and votes are not likes, so a level shift is expected; it is
  reported, not tuned on.

## Result
- Collected: 538 questions, 48 brands, 10 sites (stackoverflow 254, superuser 181, mechanics 29, android 20, gaming 14,
  apple 11, diy 11, webapps 11, travel 5, money 2); 202 requests, quota used 214 of 300 (incl. 12 spent on filter
  and debugging), 86 left. Microsoft is 195 questions (brand bootstrap handles it); median views 156.
- Primary (X + YouTube ridge): MAE 0.498 [0.448, 0.525], x3.14, median bias +0.454 (under-predicted 96%), within x2
  28%, Spearman 0.571. Variants: likes = max(score,0): 0.555, x3.59; answers only: 0.528, x3.38.
- Own-platform ridge, brand CV: MAE 0.248 [0.223, 0.272], x1.77, within x2 71%, Spearman 0.565.
- Ratio transfer / own = 1.77 > 1.5: hypothesis refuted. Almost all of the gap is the level shift (views accumulate
  for months, votes are not likes); rank (Spearman) is equal to the own-platform ridge. Not tuned on.
- E201 grid row (target Stack Exchange, factor): TikTok x2.41, YouTube x1.87, X x4.50, Facebook x3.32, Instagram x2.46,
  all five pooled x3.07, X + YouTube (grid data) x3.14. YouTube alone is best (within x2 67%) and X worst: X is again
  the source that transfers worst.
- By site: stackoverflow x2.84 (254), superuser x3.72 (181).
- Source: `data/processed/stackexchange_numbers.json`.
