# E140 · Hurdle model for zero views

## Question and hypothesis
- Question: does a two-stage model (classify views > 0, then regress on positives) beat one model? Zeros are 9 / 32 / 63
  rows (TikTok / YouTube / X, 0.4-2.5%).
- Hypothesis: no, the zeros are too few.
- Refuted if: the hurdle lowers MAE.

## Setup
- The final feature pipeline keeps only rows with views > 0, so the test is on the positive sample (the hurdle
  prediction is p * regressor and p is close to 1 there).
- Run: `python src/hurdle_zeros.py`.

## Result
| platform | zeros in raw | single | hurdle |
|---|---|---|---|
| TikTok | 9 | 0.273 | 0.273 |
| YouTube | 32 | 0.456 | 0.456 |
| X | 63 | 0.467 | 0.467 |

## Decision
No difference on the modelling sample, and the zero rows are 0.4-2.5% of the data, below the level where a hurdle can
move MAE. E31 already found two-stage models give no gain. Close the hurdle line; if zeros ever exceed a few percent,
rebuild the feature pipeline to include them.
