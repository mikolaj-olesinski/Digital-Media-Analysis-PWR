# E117 · What a 0/0 post at the first scan is worth

## Question and hypothesis
- Question: at the start a post often has 0 views and 0 likes. If Brand24 scans it early, how many views does it
  actually get? Is a 0/0 scan a hidden viral or a genuinely tiny post?
- Hypothesis: 0 reactions at the first check hides a wide range, with some large posts.
- Refuted if: a 0/0 first check almost always means a tiny post.

## Setup
- Main file: posts with 0 likes and 0 comments, all platforms.
- History file: first check (`history_1_*`), median age 11.7 h; among posts with 0 reactions at the first check, the
  views at that check and at the last check.
- Run: `python src/early_zeros.py`.

## Result
First check (690 posts, median age 11.7 h): **37.2%** have 0 reactions.
- Of those (257 posts): 85.6% have > 0 views, 6.2% > 100, **0.4% > 1k**; median 5, p90 70.
- At the last check: 93% > 0, 20.2% > 100, **3.5% > 1k**, 0.4% > 10k; median 18, p90 263.
- By platform: X median 5 (p90 49), TikTok median 60 (p90 179).

Main check (at collection): 0 reactions are common — X **64%**, YouTube **29%**, TikTok 4%.
- YouTube zero-reaction posts: 95% > 0 views, 47% > 100, **23.4% > 1k**, median 79, p90 3 383.
- X zero-reaction posts: 96% > 0, 12% > 100, 0.6% > 1k, median 13.

## Decision
A 0/0 scan is mostly a small post (median 5 views on X, 60 on TikTok), but it is not zero: 86% get some views and a
small tail (0.4% at the first check, 3.5% later) exceeds 1k. At collection time zero reactions are very common and say
little about visibility (on YouTube 23% of them exceed 1k views). So: report a range, not a point, for early posts;
and never read 0 reactions as 0 visibility. Update findings.

## Follow-ups
- A "minimum detectable" statement for a 0/0 scan: the interval, not the estimate.
- For YouTube zero-reaction posts, text and author history are the only signals (E64, E68).
