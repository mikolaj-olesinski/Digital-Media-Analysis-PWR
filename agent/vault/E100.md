# E100 · Text embeddings for the Facebook transfer

## Question and hypothesis
- Question: do multilingual-e5 embeddings of the post text add anything to likes + comments when the model is trained
  on X + YouTube and applied to Facebook?
- Hypothesis: text carries topic and format, so a few components should help a little, as they do in-platform (E50).
- Refuted if: the MAE rises.

## Setup
- Cached e5 embeddings (384 dims) reduced with PCA to 16 components fitted on the X + YouTube posts with views.
- Ridge on log1p(reactions) + log1p(comments) + 16 components, trained on X + YouTube, scored on the 130 and on 402 FB posts.
- Brand bootstrap CI.
- Run: `python src/fb_text.py`.

## Result
| set | base | + text | text only |
|---|---|---|---|
| 130 sample | **0.345** (0.281-0.435) | 0.386 (0.328-0.475) | 1.238 |
| 402 posts | **0.385** (0.312-0.482) | 0.436 (0.382-0.526) | 1.306 |

## Decision
Text hurts on FB by 0.04-0.05 MAE; the text alone is useless (x17-20 typical error). Do not add text to the FB
transfer. Consistent with E49 (context next to reactions is neutral or negative) and E50 (text helps in-platform only,
and mostly without reactions).

## Follow-ups
- If Instagram ever gets views, test text there (it resembles X/YouTube more than FB does, E81).
