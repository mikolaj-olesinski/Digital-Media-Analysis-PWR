# E94 · Do followers improve the measured Facebook transfer?

## Question and hypothesis
- Question: on the 130 Facebook posts with measured views (E93), does adding the author's follower count to the
  transfer model from X + YouTube help?
- Hypothesis: followers add a level cue for accounts of different size, so the MAE should fall.
- Refuted if: the MAE does not fall.

## Setup
- Same target and folds as E93: 130 FB Reels/videos, ridge on log1p(reactions) + log1p(comments), trained on X + YouTube.
- Added columns: `log10(followers)` and a missing flag; missing followers (42 of 130) imputed with the source median.
- Metrics: MAE log10, brand bootstrap CI, bias; paired brand bootstrap of the gain; also the subset of 88 posts with
  followers known, where no imputation is needed.
- Run: `python src/fb_transfer_check.py --followers`, 2026-11-06, seconds.

## Result
| features | MAE | 95% CI | bias | typical factor |
|---|---|---|---|---|
| likes + comments (base) | **0.345** | 0.281-0.435 | +0.06 | ×2.2 |
| + followers | 0.627 | 0.541-0.721 | +0.23 | ×4.2 |
| followers only | 1.199 | 0.934-1.413 | +0.70 | ×15.8 |

- Paired gain of "+ followers" over the base: **-0.283** (95% CI -0.361 to -0.209), i.e. clearly worse.
- Subset with followers known (88 posts): base 0.360, with followers 0.437 — still worse, so it is not the imputation.
- 130 posts, 19 brands, 88 with followers.

## Decision
Followers hurt the FB transfer on the full sample; keep likes + comments only for the global model. **Update
2026-11-06 (E149/E154):** on the 402 fetched posts the penalty is concentrated below 1M followers; above 1M followers
help (MAE 0.410 -> 0.343) and a large-page model/hybrid gains 0.410 -> 0.372 there (overall 0.385 -> 0.379, not
significant, E155). This matches E82/E88 (the CatBoost with reactions and
followers was the worst FB variant) and the earlier leave-one-platform-out result that followers do not carry across
platforms. `agent/findings.md` gets a line.

## Follow-ups
- Why: a Facebook page's followers are not the same population as a TikTok/YouTube audience, and the source
  coefficient on followers does not map to FB. Could be tested with the page's own audience size once available.
- Instagram still has no measured views (B14).
