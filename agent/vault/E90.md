# E90 · Anchor regression, group DRO and stabilised importance weights

## Question and hypothesis
- Question: do label-free robustness methods from the literature (anchor regression with the platform as anchor, linear group DRO, flattened or truncated importance weights) improve the out-of-platform ridge?
- Hypothesis (literature scan): small and uneven gains; weighting cannot fix a level shift in y given x.
- Refuted if: one method gains clearly on all three platforms.

## Setup
- Leave one platform out, target-fold brands removed (as E13). Anchor regression: sources transformed by W = I − (1 − √γ) P_A (A = source platform), least squares, γ ∈ {0, 0.5, 1, 2, 5, 10, 100}. Group DRO: weighted ridge, group weights by exponentiated gradient on group MSE (100 steps). E88 classifier weights raw, flattened (w^0.5, w^0.25), truncated at the 95th percentile.

## Result
- Anchor: γ = 0.5 0.307 / 0.602 / 0.640 vs γ = 1 (ridge) 0.312 / 0.604 / 0.641; larger γ worse (γ = 100: 0.440 / 0.625 / 0.654); γ = 0 collapses (no level).
- Group DRO: 0.302 TikTok, but 0.721 YouTube and 0.654 X.
- Weights: flattening removes the TikTok harm (0.316-0.332) and also the X gain (0.644-0.648 vs 0.618 raw weights).

## Decision
Refuted. As the benchmarks (DomainBed, TableShift, Wild-Tab, WhyShift) predict, none beats plain ridge on all platforms; changes are within ±0.01 except where they hurt. The coefficients barely move with γ, so the likes + comments ridge is already close to invariant between platforms.
