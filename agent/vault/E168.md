# E168 · How much of Brand24's rule can be recovered from the data?

## Question and hypothesis
- Question: a simple `max(k * reactions, c(followers) * followers)` fitted from the data - how much of Brand24's reach
  column does it reproduce, per platform?
- Hypothesis: it reproduces most rows on the platforms where the column is a rule (X, FB, IG) and none where reach is the
  view count (TikTok, YouTube).
- Refuted if: the reproduction share is uniform across platforms.

## Setup
- Rows with reach > 0; `k` = median(reach / reactions) per reaction bin (1-10, 11-100, 101+); `c` = median(reach /
  followers) per follower bin, only for posts without reactions.
- Predicted = max(k * reactions, c(followers) * followers); reproduced = within 1% of the actual reach.
- Run: `python src/rule_law.py`.

## Result
| platform | median k | k by reactions | follower steps (c) | reproduced within 1% |
|---|---|---|---|---|
| TikTok | - | 48 / 19 / 16 | 1.07 | **1.2%** |
| YouTube | - | 23 / 18 / 18 | 0.10 / 0.02 / 0.006 / 0.003 / 0.002 | **1.0%** |
| X | 700 | 700 / 300 / 300 | 0.10 / 0.10 / 0.09 / 0.05 | **61.9%** |
| Facebook | 108 | 274 / 100 / 100 | 0.10 / 0.10 / 0.06 / 0.04 / 0.02 | **48.6%** |
| Instagram | 20 | 20 / 20 / 45 | - | **97.0%** |

## Decision
Only Instagram is captured almost exactly by a single k and a follower fallback. On X and Facebook a simple two-branch
rule gets 62% / 49% of rows, so the real column has more structure (additional caps or bins) than the public description;
on TikTok and YouTube the column is the view count, not a rule, so reproduction near 0 is the correct finding, not a
failure. This bounds what a "reverse-engineered rule" can claim: the rule is fully recoverable on IG, approximately on
X/FB, and meaningless on TT/YT.
