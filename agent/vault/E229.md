# E229 · Instagram owner followers: do they help the IG estimate?

## Question and hypothesis
- Question: with follower counts of the reel owners (public profiles read 2026-11-09, logged-in browser agent, 585 / 587 ok), does the IG error drop?
- Hypothesis: in platform followers help a little (as on TT / YT / X, E10-style); in transfer they hurt, because follower scales differ between platforms (E87: mapped scales hurt).

## Setup
- 642 scored IG reels (ig_transfer.frame); owner from the private owner file, followers from the private profile file; 625 reels / 539 owners with followers.
- Transfer: ridge on export X + YouTube (4174 rows with followers), log likes + log comments vs + log followers.
- Own platform: ridge on IG, 5-fold CV grouped by owner and by brand; paired brand-bootstrap diffs.
- Followers are read months after the views: an upper bound for followers at read time.
- `src/ig_followers.py` (seconds, local). Only counts and errors are written; usernames stay in git-ignored files.

## Results
- Spearman log followers vs log views 0.68; followers median 1123 (p10 28, p90 26000).
- Transfer X + YT: ours x2.72, + followers x4.58 (+0.227 [0.155, 0.294]): much worse.
- Own IG, grouped by owner: likes + comments x2.38, + followers x2.23 (-0.029 [-0.036, -0.022]), followers only x3.62. Grouped by brand: x2.40 -> x2.23 (-0.032).

## Decision
Supported. Followers help inside Instagram (x2.40 -> x2.23 with IG labels) but break the transfer: X / YouTube follower counts carry a different view level than IG followers. The out-of-platform model stays on likes + comments. Bio links (cross-platform accounts, E223) still pending.
