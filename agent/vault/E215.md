# E215 · Do domain randomization and mixup let a nonlinear model transfer as well as ridge?

## Question and hypothesis
- Question: CatBoost loses to ridge when the platform is left out (E61 / E131), plausibly because trees cannot extrapolate. Does augmentation along the trend close the gap?
- Hypothesis (falsifiable): the primary variant, CatBoost + (a) trend-consistent randomization, comes within 0.03 MAE of ridge on at least 3 of the 5 targets (TikTok / YouTube / X left out, FB, IG).
- Refuted if: augmented CatBoost (primary) is still 0.03 or more worse than ridge on at least 3 of 5 targets.

## Setup
- Features C2 (log likes, log comments), export data (`em.load`, NaN -> 0 as in E131). Leave-one-platform-out over TikTok / YouTube / X (train on the other two, comparable to E131's 0.31 / 0.61 / 0.65) and X + YouTube -> FB 402 / IG reels (`results_b.targets`).
- (a) trend-consistent: K = 10 copies, x' = x + delta, y' = y + beta . delta, delta ~ N(0, 0.5) per feature, drawn per copy and per source platform; beta = unscaled ridge slope fitted on the training rows. Originals kept.
- (b) like-propensity: K = 10 copies, x' = a x + b, a ~ U(0.8, 1.2), b ~ N(0, 0.3) per feature, per copy and platform; y unchanged.
- (c) cross-platform mixup: lambda ~ Beta(0.4, 0.4) over pairs of rows from the two source platforms, 1x the training rows added.
- Models: `rt.FINAL` (CatBoost, MAE loss) and `MLPRegressor(64, 64, early_stopping)` on standardised inputs (mean of 3 seeds). Base: ridge and the plain model. Ridge is not augmented (input noise only flattens its slope).
- Paired brand bootstrap of the MAE difference vs ridge and vs the plain model (300 draws). Target views never used for selection; all variants reported.
- Queue job: `amc-augtr`, 4 CPU / 4 GiB.

## Result
MAE of log10 views (factor x10^MAE), brand bootstrap CI. diff = MAE(model) - MAE(ridge), paired brand bootstrap, + = worse than ridge. Job `amc-augtr-1108-215707`, 4 CPU, about 1 min.

- Pre-registered rule: the primary is 0.03 or more worse than ridge on 2 of 5 targets (X, IG), so the hypothesis is formally not refuted. But plain CatBoost was already within 0.03 of ridge on TikTok and YouTube (+0.018 / +0.020), and the augmentation moves CatBoost by -0.004 to +0.012 only. The rule was too loose to separate the augmentation from the base.
- Ridge is best or tied on every target. The closest nonlinear model is MLP + (b) on FB (0.385, diff -0.001 [-0.023, +0.016]).
- (b) propensity: CatBoost -0.004 / -0.012 / +0.004 / +0.020 / +0.008 vs plain (TikTok / YouTube / X / FB / IG). (c) mixup: -0.004 / +0.000 / +0.003 / +0.006 / -0.001. MLP plain is +0.022 / +0.014 / +0.077 / +0.007 / +0.009 vs ridge, and its augmentations move it by -0.012 to +0.008. All in the JSON.
- X stays the target nothing transfers to (median bias -0.44 to -0.53 for every model): a level shift, which no augmentation of the source fixes.

## Decision
No useful effect. Trend-consistent randomization does not make CatBoost extrapolate like ridge in any meaningful way (at most +0.012 vs plain, CI including 0 on FB), and no variant beats ridge on any target. The E61 / E131 conclusion stands: for transfer, use ridge on likes + comments. Augmentation for nonlinear transfer models is closed.
