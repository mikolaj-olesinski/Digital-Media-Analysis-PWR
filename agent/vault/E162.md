# E162 · Which signal does the FB transfer use?

## Question and hypothesis
- Question: does the FB transfer rely on followers, on reactions, or both? E94 found followers alone terrible (1.199 on
  130 posts); E149 found them useful for >1M.
- Hypothesis: reactions are the main signal; followers help only at the top.
- Refuted if: followers alone are competitive.

## Setup
- Ridge on the source X + YouTube with (a) followers only, (b) likes + comments, (c) both; applied to 402 FB posts.
- Run: `python src/fb_signal.py`.

## Result
| features | MAE all | MAE >1M | MAE <1M |
|---|---|---|---|
| followers only | 1.342 | 0.827 | 1.450 |
| **reactions only** | **0.385** | 0.410 | **0.380** |
| both | 0.660 | **0.343** | 0.727 |

## Decision
FB runs on reactions; followers alone are useless (1.34) but add at the top (>1M: 0.410 -> 0.343) while hurting the rest.
This is the same tier story as E149/E154. Do not use followers globally on FB.
