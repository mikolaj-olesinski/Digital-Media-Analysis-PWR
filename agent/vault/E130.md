# E130 · Intervals at posting time

## Question and hypothesis
- Question: before any reactions exist, what is the MAE and the 90% CQR band from followers, text and labels?
- Hypothesis: much wider than with reactions.
- Refuted if: the band is close to the with-reactions band.

## Setup
- Features available at posting time: log followers, missing flag, English, text length, mention type and sentiment.
- Quantile LightGBM 5/95, CQR calibrated on 25% of the training brands, 5-fold brand CV.
- Run: `python src/posting_cqr.py`.

## Result
| platform | MAE posting time | coverage 90% | width | width with reactions (E118) |
|---|---|---|---|---|
| TikTok | 0.601 | 0.893 | 2.56 | 1.14 |
| YouTube | 0.757 | 0.889 | 2.96 | 1.71 |
| X | 0.611 | 0.887 | 2.42 | 2.07 |

- Widths in log10: x360 / x900 / x260 at posting time.

## Decision
At posting time the 90% band is 2.4-3.0 log10 wide (a factor of 260-900); waiting for reactions shrinks it to 1.1-2.1.
This is the quantitative value of waiting, and the honest range for a post scanned at the start (E117/E126). Report the
range; do not report a point at posting time.
