# E93 · First measured transfer error on Facebook

## Question and hypothesis
- Question: how wrong is the views model trained on X and YouTube when it is applied to Facebook Reels and videos, now
  that 130 of the hand-check posts have a public view count measured at the same moment as their reactions?
- Hypothesis: with likes + comments the transfer is close to the in-platform error on the known platforms (0.3-0.5),
  and far better than Brand24's reach rule.
- Refuted if: transfer MAE on FB is far above the in-platform error with the same features, or Brand24's rule is close.

## Setup
- Target: 130 Facebook Reels / videos from `data/manual/fbig_sample.csv` with views fetched on 2026-11-05 (B24);
  features `log1p(reactions)`, `log1p(comments)` from the same fetch, target `log10(video_view_count)`.
- Sources: Brand24 rows of X, YouTube (and all three) with views; ridge on the same two columns (standardised).
- Baselines: Brand24 `b24_estimated_reach`; in-platform ceiling = the same two features fitted on the FB posts with
  5-fold brand-grouped CV.
- Metrics: MAE log10, brand bootstrap CI, bias (true - estimate), Spearman. Posts 130, brands 19.
- Counter choice (decision 2026-11-06): the page exposes `video_view_count` (player, used) and `play_count` (Reel
  card, median ×3.6 higher). On `play_count` the same X+YouTube model has MAE 0.686; a median shift on 5 FB posts
  brings it to 0.382, on 25 to 0.353. `plays` is kept in `data/processed/fb_fetched.csv` for audit.
- Run: `python src/fb_transfer_check.py`, 2026-11-05, seconds on the host.

## Result
| model | MAE | 95% CI | bias | typical factor | Spearman |
|---|---|---|---|---|---|
| ridge, X + YouTube | **0.345** | 0.281-0.435 | +0.06 | ×2.2 | 0.93 |
| ridge, YouTube | 0.392 | 0.338-0.471 | +0.02 | ×2.5 | 0.92 |
| ridge, X | 0.504 | 0.434-0.570 | -0.26 | ×3.2 | 0.93 |
| ridge, all three | 0.353 | 0.293-0.436 | +0.07 | ×2.3 | 0.93 |
| Brand24 reach | 1.145 | 0.854-1.440 | -0.17 | ×14 | 0.48 |
| in-platform ceiling (same features on FB) | 0.355 | 0.295-0.448 | -0.01 | ×2.3 | 0.92 |

- Adaptation with a few FB posts (200 random splits, MAE on the posts not used for calibration):
  X+YouTube 0.345 zero-shot; median shift 0.387 (k=5), 0.366 (10), 0.350 (25), 0.346 (50); slope similar or worse.
  For the biased X-only model: shift 0.504 -> 0.462 (k=50), slope 0.504 -> 0.354 (k=50), 0.367 (k=25).

## Decision
- Target definition fixed: Facebook views = `video_view_count` (player), not `play_count` (Reel card). See
  `agent/decisions.md`, 2026-11-06.
- The transfer to FB works: MAE 0.345 (×2.2), statistically indistinguishable from the in-platform ceiling 0.355 with
  the same two features; Brand24's rule is 3.3x worse and barely ranks (Spearman 0.48 vs 0.93).
- Adaptation through calibration is **not** needed when the source is X + YouTube; the level already matches. It only
  helps for a single biased source (X), where a slope on 25-50 FB posts removes the ×1.8 bias.
- Update `agent/findings.md` (transfer section). The FB caveat "no ground truth" is now replaced by "one measured
  sample, 130 posts, stratified by reactions, 19 brands".
