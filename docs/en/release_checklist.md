# Release checklist

Before publishing the repository, the preprint or the poster.

## Data and privacy

- [ ] `data/raw/` is not tracked; `logs/` is not tracked; `AGENTS.md` is not tracked.
- [ ] No author names, author URLs or post URLs in tracked files, notebook outputs or figures.
- [ ] No social handles (`@name`) in the documents; `check` warns on real social URLs, handles are a manual grep.
- [ ] The fetched Facebook files are local and git-ignored; only aggregates are committed.
- [ ] The data statement is current (FB public fetch, views vs plays, the anonymous Instagram attempt).
- [ ] The LLM labelling use is disclosed (three coders, machine-machine kappa, no human gold standard).
- [ ] No Instagram data from a logged-in session was collected; if a provider is used later, the terms are checked.

## Numbers

- [ ] Every number comes from `data/processed/*_numbers.json`; no hand-edited values.
- [ ] `python src/agent_tools.py vault && python src/agent_tools.py check` reports 0 new failures.
- [ ] `doc_status.md` is current; the "typical mistakes" list has been re-read.
- [ ] Figures exist in `_en` and `_pl` and match the numbers (`src/result_figures.py`).
- [ ] Figure labels carry no URL or handle: grep the plotting scripts (`set_title|xlabel|ylabel|text`).
- [ ] The generated guide HTML and both PPTX decks are scanned for social URLs and handles (checked 2026-11-08: none).
- [ ] `reproduce.md` works from a clean environment.

## Text

- [ ] The preprint/poster text is written by the team, not generated by an agent.
- [ ] AI use is disclosed in the preprint, as the course requires.
- [ ] Claims match `evidence_map.md` (strength) and avoid causal language.
- [ ] The Facebook >1M band, Instagram and the sample limitations are stated.

## Attributions

- [ ] TabPFN v2 weights: "Built with PriorLabs-TabPFN"; no 2.5+ weights.
- [ ] Literature entries marked "search only" are not cited as verified.
- [ ] Libraries and data sources are credited.

## Repository

- [ ] Commits are small, in English, without AI co-author lines; nothing pushed without the user.
- [ ] `requirements.txt` matches the environment used for the final numbers.
- [ ] `README.md` links the current documents (model card, status, reproduce, doc status).
- [ ] The GitHub "About" text matches `docs/en/repo_about.md`.

## License and data use

- [ ] The repository has **no license file yet**; by default that means all rights reserved. Choosing MIT/Apache-2.0 is a
      team decision (people, not an agent) and must be recorded before publishing.
- [ ] Brand24 data (the raw CSV, labels derived from it, fetched FB files) is **not redistributed**; only aggregates,
      numbers and code are published. The client owns the data.
- [ ] Public Facebook pages: the fetched counters are kept local and not republished; the paper reports aggregates and
      the method.
- [ ] Figures and text in the repository are the team's; third-party figures are not copied.
- [ ] TabPFN v2 weights are used under their license with the "Built with PriorLabs-TabPFN" attribution.
